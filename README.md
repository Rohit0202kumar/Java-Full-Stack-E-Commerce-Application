# Java Full Stack E-Commerce Application

## 📌 Project Overview

Java Full Stack E-Commerce Application is a web-based online shopping application built using React.js, Spring Boot, REST APIs, Hibernate/JPA, and MySQL. The project provides a complete frontend and backend integration for managing and displaying products.

## 🛠️ Technologies Used

- Java
- Spring Boot
- Spring MVC
- REST API
- Hibernate
- JPA
- MySQL
- React.js
- Vite
- JavaScript
- HTML
- CSS
- Bootstrap
- Git & GitHub
- Postman
- Maven

## ✨ Features

- Product listing
- Product details
- Add products to cart
- Remove products from cart
- Product management
- REST API integration
- React.js and Spring Boot integration
- MySQL database integration
- Responsive user interface
